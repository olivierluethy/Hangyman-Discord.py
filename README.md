## About The Project

I always wanted to build a game with discord.py and I never knew what game I should make. Later on I was watching a video on youtube, which was showing very good and funny python projects for beginners. The first projects were actually pretty easy. But after them there was coming hangman. And I honestly never created this kind of game. So I was investing a lot of time building this game on my own. But after that I needed some help, because there were always some shitty bugs inside this game. So I needed some help and then I was watching this [video](https://www.youtube.com/watch?v=5x6iAKdJB6U&ab_channel=NeuralNine) which helped me a lot! When I fixed those problems I came to the idea to build it also for my discord server. Because I had one and I wanted that my friends will be able to play this game to, but on this server with a bot. So I was searching a lot on the internet how to build a bot with discord.py. I already build a discord bot but with discord.js. If you are looking for a good video for this kind of project than don't forget to watch this [video](https://www.youtube.com/watch?v=4cdCDNXfcd8&t=511s&ab_channel=StartupTechTutorials) which helped me a lot.
After I could build this game the same as my pythonscript which you can play withhin the windows command prompt I was so happy. And my friends too 😄

This project cost me a lot of time. I know that a lot of people always wanted to build one themself but they had never the motivation to do that. It wasn't different with me but in some case you have to grow over and just start doing it until it runs as you want.

Here are some reasons I was willing to creat this project:
* I always wanted to have a bot which you can play with it on a discord server for friends
* Python was always a programming language which I wanted to learn and grow up my skills
* But when you once start this project and keep motivated until the end you will be happy for a long time that you have done something amazing 🙂

A list of commonly used resources that I find helpful are listed in the acknowledgements.

## Installation Guide

1. At first you need to install git on your local computer. For that you need to go to this [website](https://git-scm.com/downloads).
2. Go to your windows explorer and search for a good place for storing this project
3. Now right click on your folder or place and then click on "Git Bash Here"
4. Finally you will see a new program. If you do you only have to enter this
   ```sh
   git clone http://192.168.100.57:3000/Olivier_Luethy/Hangyman-Discord.py.git
   ```
